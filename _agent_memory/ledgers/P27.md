# P27 - Parser / memory-safety hardening
Status: DONE (first fix)

Found while testing P15: upstream nmap double-free/use-after-free of service CPE.
Root cause: getServiceDeductions does `*sd=*port->service` (shallow copy, borrowed cpe ptrs); reused sd's
erase() then frees those borrowed ptrs on a later service==NULL port. Valgrind: invalid free in
serviceDeductions::erase() <- getServiceDeductions; invalid reads in cpe_get_part.
Fix: add serviceDeductions::reset() (no free, cpe.clear()); use it instead of erase() at portlist.cc:270.
Other two erase() sites operate on owned data, unchanged. Post-fix valgrind: 0 errors.
Test: tests/improvements/P27/run.sh (-sV open(CPE)+closed must not crash). Repro: nmap -sV -p 8123,8124 (http on 8123).
