# P24 — Honeypot / tarpit / fake-response detection

Status: IN_PROGRESS

## (A) DESIGN

### Problem
Honeypots (Cowrie, OpenCanary, Conpot), TCP tarpits (LaBrea-style), and deceptive
firewalls/middleboxes deliberately falsify scan responses — typically by making a
huge number of ports look "open" and/or returning identical/empty banners on all of
them. Stock Nmap happily reports these as real open ports, poisoning results. There
is no built-in "is this host lying to me?" check.

### Approach
Add an NSE **host script** `honeypot-detect.nse` (categories: discovery, safe) that
runs after the port scan and flags fake-response hosts from the scan results, using
the NSE port table (`number`, `state`, `reason`, `version.{name,product,version}`):

1. **Excessive open ports** — an implausible number of open TCP ports (default >= 30,
   `honeypot-detect.minopen`) is a strong honeypot/tarpit signature.
2. **Uniform banners** — a large fraction of open ports sharing one identical service
   signature (default >= 10 and >= half of open ports, `honeypot-detect.uniform`).
   This also catches the "all ports open, no banner" tarpit/blackhole-accept pattern
   (the shared signature is simply "unknown").

It emits a structured verdict (LIKELY / POSSIBLE) plus the concrete indicators and an
open-port count, so the result is both human- and machine-readable (and appears in the
P05 JSON host scripts).

Conceptually this is the host-level companion to P14: P14 scores how trustworthy a
single port state is; P24 looks across all ports for the *collective* pattern of a host
that fabricates openness.

### Files
- NEW `scripts/honeypot-detect.nse`
- `scripts/script.db` regenerated (`./nmap --script-updatedb`) so it's selectable by name/category.
- Doc + test (python multi-port fake responder).

### Test strategy
Stand up a python "honeypot": ~40 TCP listeners on localhost all returning the same
banner. `nmap -sV --script honeypot-detect` must return a LIKELY verdict with both
indicators. Negative control: a single normal HTTP port must NOT be flagged.
