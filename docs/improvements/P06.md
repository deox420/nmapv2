# P06 — Exporters to security standards (SARIF / OCSF / STIX)

## Synopsis

```
nmap -sV -oJ - <target> | tools/nmap-export.py --format sarif
tools/nmap-export.py --format ocsf scan.json -o scan.ocsf.json
tools/nmap-export.py --format stix scan.json
```

## Description

Nmap output is Nmap-shaped. Modern security platforms prefer *standard* formats:
**SARIF 2.1.0** (CI / code-scanning surfaces such as GitHub), **OCSF** (SIEM and
data-lake normalization), and **STIX 2.1** (threat-intel / CTI sharing). P06 ships
`tools/nmap-export.py`, a dependency-free (stdlib-only) converter that reads the
stable native JSON from P05 (`-oJ`) and emits any of the three.

Building on the JSON rather than threading three elaborate schemas through the C
core keeps each mapping small, isolated and easy to maintain — and lets the export
reuse the fork's reliability scores (P14) and diagnostics (P15).

Each **open port** becomes one finding/object, with host context (address,
hostnames, service) attached:

| Format | Shape |
|--------|-------|
| SARIF 2.1.0 | one `run` (tool driver `nmap`), rule `nmap/open-port`, a `result` per open port; host/port/service/reliability in `properties`, endpoint in `logicalLocations`. |
| OCSF | array of Network Activity findings (`category_uid` 4, `class_uid` 4001) with `dst_endpoint`, `connection_info`, observables and `metadata.product = nmap`. |
| STIX 2.1 | a `bundle` of SCOs: an `ipv4-addr`/`ipv6-addr` per host, a `network-traffic` per open port (`dst_port`, `protocols`), and a `software` object per detected service. IDs are deterministic (`uuid5`) so the same scan yields the same bundle. |

The tool reads a file argument or stdin, writes stdout or `-o <file>`, and rejects
input that is not Nmap JSON with a clear error and a non-zero exit.

## Examples

```
# Upload Nmap findings to a SARIF-aware dashboard
nmap -sV -oJ - 10.0.0.0/24 | tools/nmap-export.py -f sarif -o nmap.sarif

# Normalize to OCSF for a data lake
tools/nmap-export.py -f ocsf scan.json | jq '.[].dst_endpoint'

# Produce a STIX bundle for CTI sharing
nmap -sV -oJ - host.lab | tools/nmap-export.py -f stix > host.stix.json
```

## Verification

Reproducible test: [`tests/improvements/P06/run.sh`](../../tests/improvements/P06/run.sh).
It scans a real localhost HTTP service to JSON, converts to all three formats
(exercising stdin piping), and asserts each is well-formed and contains the open
port — a SARIF 2.1.0 result, an OCSF class-4001 finding, and a STIX bundle with an
`ipv4-addr` plus a `network-traffic` object on the right `dst_port`. It also checks
that non-Nmap JSON is rejected cleanly.
